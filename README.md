🛒 E-Commerce Sales Analysis & Interactive Excel Dashboard

## 📌 Project Overview

This project is an **interactive E-Commerce Sales Analysis Dashboard built in Microsoft Excel**.

The objective of this project is to analyze e-commerce sales data and transform raw data into meaningful business insights related to **sales, profit, quantity, monthly performance, and regional trends**.

The dashboard uses Excel's data analysis and visualization features to make the information easy to understand and support data-driven decision-making.
## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall sales and profit performance
- Identify monthly sales and profit trends
- Analyze regional sales performance
- Understand product/category performance
- Compare sales and quantity across different segments
- Identify patterns and trends in the data
- Create an interactive dashboard for business analysis
- Present complex data in a simple and professional visual format

## 📈 Key Excel Techniques

### Pivot Tables

Pivot Tables were used to summarize and analyze large amounts of sales data efficiently.

### Slicers

Interactive slicers allow users to filter the dashboard and explore specific portions of the dataset.

### SUMIFS

`SUMIFS` was used to calculate sales, profit, and other metrics based on multiple conditions.

### Conditional Formatting

Conditional formatting was used to highlight important values, trends, and differences in the data.
